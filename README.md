THIS IS THE PROJECT THAT I MADE DURING MY ITNERNSHIP AT IRDE, DRDO.
THIS PROJECT AIMS TO PROVIDE A COST EFFECTIVE WEARABLE SOLUTION FOR VISUALLY IMPAIRED, PROVIDING THEM ASSISTANCE ABOUT THE OBJECT IN FRONT OF THEM.
THIS WAS AN IOT+AI PROJECT WHICH USES ESP-32 soc and cam FOR OBJECT DETECTION AND REQUIRES AN ANDROID SMARTPHONE TO RUN THE APP, IT DOESN'T REQUIRE ANY INTERNET CONNECTIVITY FOR THE INFERENCE OF THE DEEP LEARNING BASED MODEL MAKING IT RELIABLE.
THROUGHOUT THIS PROJECT I GOT TO LEARN ABOUT AI, ML, DL, TTS, OBJECT CLASSIFICATION, DIMENSIONALITY REDUCTION, IMAGE ENHANCEMENT TECHNIQUES, OPENCV, ANDROID DEVELOPMENT, AND MUCH MORE.
